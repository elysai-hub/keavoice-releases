# Kea Voice — bản phát hành

Ghi âm và phiên âm cuộc họp, chạy ngay trên máy của bạn.

Tải bản mới nhất ở mục **[Releases](https://github.com/elysai-hub/keavoice-releases/releases/latest)**:

| Hệ điều hành | File |
|---|---|
| macOS (chip Apple M1 trở lên) | `KeaVoice-<phiên bản>.dmg` |
| Windows 10/11 (64-bit) | `KeaVoice-<phiên bản>-x64-setup.exe` |

App đã cài tự kiểm tra và cập nhật từ đây (`appcast.xml` cho macOS, `latest.json` cho Windows).
Repo này chỉ chứa bản phát hành, không chứa mã nguồn.
